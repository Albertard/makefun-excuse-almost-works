# The Excuse That Almost Works

A program that writes exactly one line to `/output/entry.txt` — the excuse a gamer texts the boss to skip work on GTA 6 launch week. Built for the make.fun competition **"The Excuse That Almost Works"** (`u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5`).

## The excuse

> My keyboard died overnight and I'm typing this on my TV remote, can't do anything till the new one arrives

The excuse works because it is a real, specific, boring workplace detail — a dead keyboard — rather than a wild story, so a tired manager who has heard every excuse twice would almost believe it. The laugh comes from the excuse's own logic: the text proves itself, because it really does read like it was typed in a hurry on a TV remote, and the manager can picture it. It is a fresh angle — no dead grandmother, no flat tyre, no sudden fever — and it reads exactly like a hurried text: plain words, no setup, no explanation, no signature. The "almost" is the giveaway a manager would spot a second later (an on-screen keyboard exists), but for one line, it almost works.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
